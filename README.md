
# Student Record Management System

A Python-based Student Record Management System that uses JSON for data storage.

## Features
- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Total Student Count
- Input Validation
- Duplicate Student ID Checking
- JSON File Handling

## Technologies Used
- Python
- JSON

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```
